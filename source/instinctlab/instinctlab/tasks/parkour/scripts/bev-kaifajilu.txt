## 技术细节

### 相机内参
```
fx: 720.6
fy: 820.1
cx: 320.0
cy: 160.0
分辨率: 640 × 360
```

### 深度图转BEV流程

1. **读取深度图**: 归一化PNG (0-255) → 反算米深度 (depth / 255 * 10.0)
2. **像素→相机坐标**:
   - x_cam = (cx - u) * depth / fx
   - y_cam = (v - cy) * depth / fy
   - z_cam = depth
3. **相机→地面坐标**:
   - x_flat = x_cam
   - y_flat = z_cam (深度方向)
   - z_flat = abs(y_cam)
4. **地面→世界坐标** (假设相机水平安装，高度0.5m):
   - world_x = x_flat * cos(yaw) - y_flat * sin(yaw) + robot_x
   - world_y = x_flat * sin(yaw) + y_flat * cos(yaw) + robot_y
5. **BEV网格填充**: 根据世界坐标填充对应的BEV像素

### BEV参数
```
BEV范围: X[-2, 2]m, Y[0, 4]m (机器人前方4米)
BEV分辨率: 0.01m/pixel
BEV尺寸: 400 × 400 像素
```

### 摔倒率地图
```python
def get_preset_fall_rate(world_x, world_y):
    """预设摔倒率"""
    in_danger_zone = (3.5 <= world_x <= 4.5 and 1.5 <= world_y <= 2.5)
    return 0.8 if in_danger_zone else 0.1
```

## 下一步计划

### 方案A: CNN回归摔倒率网格
```
输入: 640×360 深度图
输出: 5×5 摔倒率网格
模型: ResNet18 + 1×1 Conv
训练: 监督学习，标签来自预设摔倒率地图
部署: 64×36 深度图 upscale 到 640×360
```

### 方案B: 直接使用深度特征
```
输入: 640×360 深度图
输出: 每像素摔倒率
模型: U-Net 类似结构
标签: 摔倒率地图投影到图像平面
```

### 推荐方案A
理由:
1. 5×5网格足够局部规划
2. 模型小、推理快
3. 标签生成简单
